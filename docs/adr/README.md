# Architecture Decision Records

## Formato

```markdown
# NNNN - Titulo

## Status
Proposto | Aceito | Substituido por NNNN

## Contexto
Qual forca obriga uma decisao.

## Decisao
O que foi decidido.

## Alternativas consideradas
O que foi rejeitado e por que.

## Consequencias
O que fica mais facil, o que fica mais dificil, o que passa a ser obrigatorio.
```
